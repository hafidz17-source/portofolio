Tentang Saya

Mahasiswa Universitas Pamulang yang memiliki ketertarikan besar pada dunia teknologi, khususnya Cloud Computing, Internet of Things (IoT), Embedded Systems, Machine Learning, dan Hardware Engineering. Aktif mengeksplorasi berbagai teknologi melalui proyek praktis, mulai dari pengembangan sistem monitoring energi listrik berbasis ESP32, integrasi sensor dan database, hingga penerapan algoritma XGBoost untuk prediksi konsumsi energi.

Memiliki pengalaman mengembangkan dan menyimulasikan proyek berbasis Arduino, sistem presensi menggunakan QR Code dinamis dan Location-Based Service (LBS), smart door lock berbasis NFC, serta otomasi menggunakan PLC. Juga tertarik mempelajari Linux, Ubuntu Server, Docker, Node-RED, dan pengembangan layanan berbasis web untuk membangun sistem yang terintegrasi.

Di luar pengembangan perangkat lunak dan embedded systems, saya gemar mengoprek hardware komputer, mengoptimalkan performa PC, mengeksplorasi sistem operasi, serta mempelajari teknologi baru melalui eksperimen langsung. Saya percaya bahwa pemahaman teknologi terbaik diperoleh melalui kombinasi teori, praktik, dan proses pemecahan masalah secara berkelanjutan.

Fokus saya adalah terus mengembangkan kemampuan di bidang teknologi, membangun proyek yang bermanfaat, dan mengintegrasikan hardware, software, jaringan, serta kecerdasan buatan menjadi solusi yang inovatif dan aplikatif.
